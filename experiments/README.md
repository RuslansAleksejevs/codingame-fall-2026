# Experiments

For every run, record its purpose, command, versions, input data, cost, actual results and conclusion. Preserve all outcomes and distinguish game losses from technical failures. Use a new directory for every run; keep frozen sources and source hashes.

Complete records and logs are stored in adjacent `records.tar.gz` archives. Restore them with `python3 code/restore_records.py`. The latest comparison is under `2026-11-05-attack/`; earlier incremental experiments remain under `2026-11-05-incremental/`.

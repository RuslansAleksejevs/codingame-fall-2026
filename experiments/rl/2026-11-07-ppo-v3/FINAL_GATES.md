# Final-evidence implementation safeguards

Recorded before any final candidate or reserved map is opened, 8 Nov 2026.
The original `PROTOCOL.md` promotion criteria are unchanged. This file describes
their executable checks, not a new experiment or result.

`freeze_finalist.py` accepts the leading admissible policy in a verified full
40-map development ranking, after both independent continuations and closure
of the search branch. An explicit research-complete flag is required. Inspect
processes before using it: a status file alone cannot prove that unrelated or
later jobs have exited. No further learning/selection after this freeze.

The freeze copies weights without touching the old policy, pins sources and
criteria, rebuilds known map-content exclusions, and prepares but does not run
the final panel. It packages both the candidate and base, so the timed final
panel tests their actual single-source programs. Both packages must pass exact
weight/replay checks on already exposed development records before the final
panel starts. There can be only one `finalist` directory. The 100 maps are
not generated by the freeze. The original arena rejects a content collision.

The final panel is exactly 2,200 games on seeds40001--40100, both seats:
candidate/base each versus Lacoz, both khoufou versions, v6 and BC, plus direct
candidate--base. All records and technical outcomes remain in the archive.
The panel stops starting games at07:00UTC9Nov, leaving time before09:00 for
verification/platform preparation. Research must already have stopped by02:00.

`final_evidence.py` requires a preceding weight freeze, correct weights in the
panel, all 2,200 unique assignments, native/Java verification, and zero content
overlap. Comparisons use only paired clean outcomes on identical maps. Technical
wins are not strategic gains. Whole-map bootstrap intervals keep the two seats
together; uncertainty is over maps/games, not over training seeds.

Promotion evidence requires direct score >=55% and its map-bootstrap lower95%
bound >50%; equal-weight external gain >=3 percentage points; no external
matchup drop >5 points; zero own technical failure. As a conservative coverage
safeguard, each matchup must also retain at least180/200 clean comparisons.
Insufficient coverage is inconclusive, not permission to discard failures or
selectively rerun. Composite intervals report their complete-map coverage.

If any criterion fails, keep league3m; do not tune on this holdout or silently
select another tested finalist. A passing local result still does not submit
anything. Packaging must verify exact weights and replay commands, then the
official platform check requires read/play OAuth but not submit authorization.

Synthetic gate tests use only artificial outcome rows and literal seed IDs.
They do not generate/read maps or constitute played games.

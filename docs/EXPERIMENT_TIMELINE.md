# Experiment timeline: from heuristics to the requested leaderboard recheck

Prepared 8 November 2026 from the preserved reports, protocols, manifests and
official API records. This is a retrospective index, **not a rerun** of those
experiments. The current requested live check has its own final section.

## How to read the evidence

- Dates explicitly marked **PST** use America/Los_Angeles, UTC−08:00. UTC entries
  use recorded event/API times. A date-only report does not establish an exact
  start time; none is inferred from a commit or file modification time. In
  particular, the `2026-11-06-live-ppo-v2` directory contains **7 November UTC**
  platform events.
- Local measurements are **PROJECT_REPORTED**; official saved platform responses
  are **SOURCE_VERIFIED**. Explanations and recommendations are **MODEL_INFERENCE**.
  Unknown causes remain **UNKNOWN**. Public opponents are attributed benchmark
  sources, not original project algorithms or independently replicated upstream
  leaderboard claims.
- A fresh execution on an old map is **not a fresh-map test**. Replayed trajectories,
  exact repeats, training episodes, development selection and independent final
  matches are different quantities. Counts below must not be added into one
  purported independent sample.
- Intervals are 95% whole-map paired bootstrap intervals unless noted; both seats
  remain together. They do not establish robustness across training seeds or
  predict the live field. Technical wins/losses and clean-paired results are
  distinguished. Zero observed errors is not a universal reliability guarantee.
- Exact commands, environments, hashes and raw-record/archive pointers are in each
  linked report and manifest. No historical raw file or negative result was
  overwritten to create this index. Historical reports describe their own cutoff;
  [STATUS](STATUS.md) supplies the current interpretation.
